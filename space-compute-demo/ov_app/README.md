# ov_app

Omniverse Kit application + 7 `space.demo.*` extensions.

## Layout

- `apps/space.demo.viewer.kit` — main Kit application (generated from USD Viewer template in Phase 1).
- `exts/space.demo.core` — bootstrap + stage load.
- `exts/space.demo.scene` — projects backend state onto USD prims.
- `exts/space.demo.messaging` — Web ↔ Backend ↔ Kit message bridge.
- `exts/space.demo.timeline` — sim clock mirror + interpolation.
- `exts/space.demo.selection` — pick handling.
- `exts/space.demo.task_maritime` — maritime case overlay (sea AOI, detection, DrawLines link).
- `exts/space.demo.camera` — named camera presets.

## Generation

The Kit app + setup/messaging extensions are generated by NVIDIA's `repo template new`.
See [../docs/kit_setup.md](../docs/kit_setup.md).

Authored extensions (`space.demo.{core, scene, timeline, selection, task_maritime, camera}`) live here directly.
