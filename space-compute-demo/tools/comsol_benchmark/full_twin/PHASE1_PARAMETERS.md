## Phase 1b — the OrbitWiz lumped thermal network, in my own words

- **Nodes.** Exactly **one** thermal node: `SatelliteState.temperature_c` — "the structure", which is simultaneously the bus, the GPU cold plate and the radiator (state_engine.py:1880-1894). The **GPU die** is a quasi-static algebraic node on top of it: `T_die = T_struct + P_gpu * R_th` (llm_perf.py:338). The **solar array** has its own algebraic equilibrium temperature (`_array_temp_c`, state_engine.py:133-159) used only for the cell eta(T) derate; it is explicitly decoupled from the bus (no heat exchange).
- **Conduction paths.** None between finite-capacity nodes (single node). The only "conductance" is die→structure `R_th` (V100 0.12, A100 0.085, H200 0.060, B200 0.045 K/W; llm_perf.py:107/118/126/134).
- **Radiation to space.** `Q_out = eps * sigma * A_rad * T^4` with `A_rad = 2 panels x 2 faces x long x short` (state_engine.py:517-523, 1886) — both faces of both radiator panels, view factor 1 to a 0 K sink (no T_amb term), no orientation dependence, no self-view, no bus/array radiation.
- **85 °C limit.** Applied to the **GPU die node**: budget `P_limit = (T_throttle - T_struct)/R_th` (llm_perf.py:283-285); if `P_limit <= 1.02 * P_static` → runaway. `T_throttle` is 85 °C for A100/H200/B200 but **83 °C for V100** (llm_perf.py:107).
- **Environmental fluxes** (state_engine.py:478-490): solar `alpha*S*illum*A_rad/4` (convex-body mean projected area, no attitude); albedo `alpha*0.30*S*A_rad*F*max(0, r_hat.s_hat)`; Earth IR `eps*237*A_rad*F`. `F = (1 - sqrt(1 - (R/r)^2))/2` with R = 6371 km (geodyn.py:206-212) — a sphere-to-Earth factor applied to the total area. Sun: analytic Vallado (`geodyn.sun_teme`); eclipse: conical umbra/penumbra disc fraction. `S = 1361 / d_AU^2`.
- **Heat input.** `Q_in = (P_payload + P_platform) * 0.95 + Q_env` (state_engine.py:1885); per-GPU heat is identical to per-GPU electrical draw (ai_workloads.py:235, 300).
- **Capacity.** `THERMAL_MASS_J_PER_K = 160 000` (state_engine.py:1890; comment: "Picked here for legible dynamics"). Temperature is clamped to [-80, 95] °C (line 1894).
- **Attitude.** Default `attitude_mode = "free"` (models.py:204): array normal = orbit normal r x v, incidence |n.s| (state_engine.py:466-470). NB `docs/physics.md` §3 still says "free incidence = 0.95" — stale; the code is authoritative.

## Phase 1e — NOT FOUND (per Hard Rule 2 I stop here)

1. **Material properties (rho, cp, k) for every component** — bus, radiator, solar array, GPU blade, battery. OrbitWiz has no material model; the USD assets carry render shaders only. The only capacity in the model is the tuned 160 kJ/K.
2. **Mass attributes in the USD assets** — none. Sanity Check 0 (density x volume vs USD mass) **cannot be performed as specified**; only the preset's areal-density estimate exists (derived).
3. **GPU-to-baseplate contact conductance** — none. The only thermal resistance is junction→structure `R_th`, which llm_perf.py:92-95 documents as an assumption (V100 fitted, others relative guesses). Using it makes the die-temperature part of the comparison circular; I will treat it as *not* primitive.
4. **Baseplate-to-radiator conduction path** — none (no baseplate node, no radiator node, no conductance).
5. **Real (structural) radiator panel thickness** — the 0.095 m scan thickness is a visual prop; with any metal density it would weigh hundreds of kg per panel.
6. **Body-frame yaw about the array normal** — the "free" attitude fixes only +X (cell normal) = ±orbit normal. Which of body ±Z / ±Y points nadir or along-track is undefined, so the sun vector in body frame is defined only in its X component.
7. **Battery geometry / mounting** and **platform-power dissipation location**.
8. **Per-face optical properties** — both radiator faces share one alpha/eps; the array has a single alpha and one eps per face (front = back).
